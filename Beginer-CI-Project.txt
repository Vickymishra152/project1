#Jenkinsfile

pipeline {
    agent any

    stages {
        stage('Install Dependencies') {
            steps {
               sh '''
               python3 -m venv venv
               . venv/bin/activate
               pip install --upgrade pip
               pip install -r requirements.txt
               '''



            }
        }

        stage('Run Tests') {
            steps {
                sh 'venv/bin/python3 -m pytest --maxfail=1 --disable-warnings -q'
            }
        }
    }

    post {
        always {
            echo 'Build Finished'
        }
    }
}

Question:

"How do you integrate GitHub with Jenkins for CI, and how does Jenkins detect changes in the repository?"

Answer (Step-by-Step):

Integrating GitHub with Jenkins:

Install the Git and GitHub plugins in Jenkins.

Create a GitHub Personal Access Token and add it as a credential in Jenkins.

In Jenkins job configuration, set Source Code Management → Git, provide the repo URL, and select the credentials.

Optionally, use a Jenkinsfile in the repo to define the pipeline.

Detecting Changes:

Poll SCM: Jenkins periodically checks GitHub for changes (e.g., every minute). If changes exist, it triggers the pipeline.

Webhook (optional): GitHub can notify Jenkins immediately when a push occurs. This is more efficient than polling.

CI Process Example:

Jenkins pulls the latest code from GitHub.

Installs dependencies (e.g., pip install -r requirements.txt for Python).

Runs tests (e.g., pytest).

Reports build status (success/failure).

Why This Is Important:

Ensures automated, fast feedback after each code change.

Reduces manual testing and integration errors.

Enables continuous integration and delivery practices.
